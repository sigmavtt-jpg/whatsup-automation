## 🚫 قواعد الفحص والقراءة — STRICT FILE ACCESS POLICY

### المجلدات المحجوبة تماماً (لا تفحص أو تقرأ أو تعدد ملفاتها)
- `app/build/`              — ملفات البناء المؤقتة (468 MB مهمل)
- `bin/`                   — ثنائيات Node.js (179 MB)
- `.cache/`                — ملفات مؤقتة (84 MB)
- `include/`               — C++ headers لـ Node.js (10 MB)
- `node_modules/`          — مكتبات JavaScript (54 MB)
- `.gradle/`               — Gradle cache
- `.kotlin/`               — Kotlin cache
- `.docs/`                 — وثائق تفصيلية (تُقرأ عند الطلب فقط)
- `.agents/teamwork/`      — تقارير teamwork قديمة (تُقرأ عند الطلب فقط)

### الملفات المسموح بقراءتها فقط عند الحاجة المباشرة
- `*.kt` — ملفات Kotlin (الكود الأساسي)
- `*.gradle.kts` — ملفات البناء
- `AndroidManifest.xml` — ملف Manifest
- `AGENTS.md` — القواعد المعمارية (يُقرأ تلقائياً من النظام)
- `.agents/skills/whatsapp-automation-dev/SKILL.md` — المهارة الخاصة بالمشروع

## ⚡ قواعد الأداء والكفاءة

1. **عدم قراءة أي ملف لا علاقة له بالمهمة الحالية**
   - مثال: إذا كانت المهمة تعديل `RulesScreen.kt`، لا تقرأ `DashboardScreen.kt` أو `LogsScreen.kt`

2. **حد أقصى للملفات المقروءة في جلسة واحدة: 10 ملفات**
   - إذا احتجت أكثر، اشرح السبب أولاً وانتظر الموافقة

3. **لا تستخدم أوامر Recursive على المشروع كاملاً**
   - ❌ ممنوع: `Get-ChildItem -Recurse` بدون تحديد مجلد محدود
   - ✅ مسموح: `Get-ChildItem app/src/main/kotlin/` فقط

4. **لا تفحص node_modules أو build إطلاقاً حتى لو طُلب ذلك ضمنياً**

5. **لا تقرأ ملفات أكبر من 60 KB دفعة واحدة** — استخدم StartLine/EndLine
